# System-of-Systems Orchestration

Transform the request into an execution architecture rather than a collection of disconnected tasks.

## 1. Frame the mission

Capture:

- objective and expected outcome;
- decision owner and stakeholders;
- systems, departments, platforms, jurisdictions, and data affected;
- constraints, dependencies, interfaces, deadlines, and exclusions;
- measurable acceptance criteria.

## 2. Map the system

Create a lean map of:

- components and boundaries;
- upstream and downstream dependencies;
- information, control, financial, operational, and evidence flows;
- human roles, AI roles, virtual agents, and validation authority;
- single points of failure and interoperability risks.

Avoid a “gas factory”: every agent, tool, control, meeting, and artefact must have a justified purpose, owner, input, output, and stop condition.

## 3. Apply operating modes

Use the mode appropriate to each role:

- Human-led, AI-assisted;
- AI-led, human-supervised;
- AI-executed, mandatory human validation.

Use temporal layers when relevant:

- RETRO: audit, recover, normalize, document, and capitalize prior work;
- NOW: execute current operations and controls;
- FUTURE: design scalable target-state architecture and roadmap.

## 4. Route work

Separate at least these concerns for substantial work:

- research and evidence collection;
- architecture and decision design;
- implementation;
- security, risk, legal, quality, and compliance review;
- independent assurance and release decision.

Parallelize only independent workstreams. Define inputs, outputs, permissions, acceptance criteria, and integration points for each delegated task.

## 5. Control execution

Maintain:

- decision register;
- assumptions and unverified-claims register;
- risk and control register;
- evidence register;
- change log and version;
- validation results;
- rollback and recovery path.

## 6. Measure value

Select a small set of outcome KPIs, such as:

- acceptance-criteria pass rate;
- defect escape rate;
- cycle time and rework rate;
- control effectiveness;
- evidence completeness;
- security findings by severity;
- human validation turnaround;
- cost, reliability, availability, and user-impact metrics.

## 7. Deliver

Provide an integrated result with architecture, responsibilities, workflow, controls, evidence, residual risks, readiness status, and the next controlled action.
